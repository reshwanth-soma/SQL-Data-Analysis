SQL Data Analysis

Objective
Use SQL queries to extract and analyze data from an E-commerce dataset (Online Retail II) with PostgreSQL.  
This task demonstrates skills in querying, aggregating, joining, creating views, and optimizing SQL queries.


Dataset
- Name: Online Retail II (Kaggle dataset)  
- File: `online_retail_II.csv`  
- Columns: Invoice, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country  


Tools Used
- PostgreSQL (SQL execution)  
- pgAdmin / psql  
- CSV dataset  

Queries Implemented
1. SELECT, WHERE, ORDER BY, GROUP BY 
2. JOINS (INNER, LEFT, RIGHT)  
3. Subqueries  
4. Aggregate Functions (`SUM`, `AVG`)  
5. Views for Analysis 
6. Indexes for Optimization
